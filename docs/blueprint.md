# **App Name**: GastronomicAI

## Core Features:

- Menu Analyzer: Analyze menu item descriptions using a generative AI tool to extract key ingredients, allergens, and nutritional information.
- Dietary Filter: Allow users to filter menu items based on dietary restrictions (e.g., vegetarian, gluten-free) identified by the Menu Analyzer.
- Personalized Recommendations: AI-powered recommendations using a tool which factors user preferences, dietary needs and the restaurant's menu.
- Menu Display: Display the restaurant's menu with clear descriptions, pricing, and dietary flags.
- Image integration: Integrate high-quality appetizing menu images for each item to improve customer engagement.
- Restaurant Information: Provide essential details such as address, contact number, opening hours, and customer reviews.

## Style Guidelines:

- Primary color: Saturated reddish-orange (#D3470A) to evoke appetite and energy.
- Background color: Desaturated light orange (#F8EFE9) to give warmth and a subtle backdrop.
- Accent color: Yellow-orange (#E08B39) for interactive elements and highlights.
- Body font: 'PT Sans', a humanist sans-serif providing a modern, clean, and easily readable appearance. Suitable for both headings and body text.
- Use minimalist, line-based icons relevant to food categories and dietary filters.
- Employ a card-based layout for menu items with clear separation and intuitive navigation.
- Implement subtle transitions and animations on hover and content updates to enhance user experience.
